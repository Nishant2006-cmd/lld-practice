# Research Note

## Why LLD Practice is Hard
- Learners struggle to apply OOP principles in real-world problems.
- Existing platforms focus on coding challenges, not design.

## Existing Tools
- LeetCode, HackerRank - focus on algorithms.
- No dedicated platform for iterative LLD practice.

## Gap
- Lack of structured feedback on design quality.
- No iterative loop for learners to improve designs.

## Product Direction
- Provide problem sets.
- Allow learners to submit designs.
- Give feedback (deterministic + AI).
- Enable iterative improvement.

## Key Insights
- Feedback must be explainable, not just a score.
- Multiple valid solutions exist, so evaluation should highlight trade-offs.
- Iteration history is important for learning progression.

## Next Steps
- Build MVP with problem selection  , submission, evaluator, and feedback.
- Extend later with attempt history db andlogic.
